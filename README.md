# Cinemax Player

مشغّل فيديو مستقل لأندرويد: الصق أي رابط وشغّله. المحرك Media3 (ExoPlayer) والواجهة بتصميم Cinemax.

## البناء على GitHub (بدون أي إعداد)

1. أنشئ مستودعاً جديداً وارفع **كل** محتويات هذا المجلد (انتبه أن مجلد `.github` المخفي يُرفع أيضاً).
2. افتح تبويب **Actions** وانتظر انتهاء "Build Android APK" (نحو 8 إلى 12 دقيقة)، أو شغّله يدوياً بزر **Run workflow**.
3. ادخل على آخر تشغيل ونزّل **CinemaxPlayer-APK** من قسم Artifacts. بداخله:
   - `CinemaxPlayer-universal.apk` يعمل على كل الأجهزة.
   - `CinemaxPlayer-arm64-v8a.apk` أصغر حجماً وهو المناسب لمعظم الجوالات الحديثة.
4. لإصدار على صفحة Releases: أنشئ tag يبدأ بـ `v` مثل `v1.0.0` وسترفع الـ APK تلقائياً.

التوقيع بمفتاح debug، ويثبّت عادي على الجوال. للنشر في Google Play تحتاج مفتاح توقيع خاصاً بك.

## البناء على جهازك

```
sh tool/bootstrap.sh        # ينشئ مشروع أندرويد ويطبّق ملفات android_overrides
flutter build apk --release
```

المطلوب Flutter 3.38 وJava 17.

## الروابط والصيغ المدعومة

- **HLS** (`.m3u8`) و**DASH** (`.mpd`) و**Smooth Streaming** (`.ism`).
- ملفات مباشرة: MP4, MKV, WebM, MOV, AVI, FLV, TS, 3GP, MPEG، وصوت MP3, M4A, AAC, FLAC, OGG, WAV.
- **RTSP**، وروابط `content://` و`file://` القادمة من مدير الملفات.
- روابط بلا امتداد: التطبيق يفحص بداية الرابط ويتعرف على الصيغة، ويمكنك أيضاً اختيار الصيغة يدوياً.
- لصق رسالة كاملة تحتوي رابطاً يكفي، والتطبيق يستخرج الرابط. روابط Dropbox تتحول لرابط مباشر.
- خيارات متقدمة: ترويسات HTTP (Referer, Cookie, Authorization...) وUser-Agent ورابط ترجمة (vtt / srt / ass).
- "فتح بواسطة": اضغط رابط فيديو في المتصفح أو شاركه من أي تطبيق واختر Cinemax Player.
- آخر الروابط تُحفظ، ويكمل التشغيل من آخر موضع.

غير مدعوم: روابط صفحات مثل YouTube، لأنها ليست روابط وسائط مباشرة. وRTMP غير مضمّن.

## ميزات المشغّل

- جودة الفيديو: Auto أو دقة محددة، وتبقى العلامة على اختيارك.
- قائمة More: السرعة، نسبة العرض (Fit / Fill / Zoom)، ومدة التقديم والترجيع (5 / 10 / 15 ثانية).
- نقر مزدوج يمين/يسار للتقديم والترجيع مع أنميشن يجمع الثواني.
- ضغط مطوّل لتسريع التشغيل: يبدأ 2.0x، سحب لليمين حتى 5.0x ولليسار حتى 0.5x، وعند الرفع تعود السرعة السابقة.
- ترجمات مدمجة وخارجية تُعرض فوق الفيديو، واختيار الصوت، وقفل الشاشة، وصورة داخل صورة.

## بنية المشروع

- `lib/` واجهة التطبيق (إدخال الرابط، السجل).
- `packages/cinemax_player/` وحدة المشغّل (Dart + Java).
- `android_overrides/` ملف الـ Manifest والأيقونات وفلاتر "فتح بواسطة"، يُطبَّق فوق مشروع أندرويد المولَّد.
- `.github/workflows/build.yml` بناء الـ APK على السحابة.
